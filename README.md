# Sai Bhaskar — Portfolio

Responsive personal portfolio built with HTML, CSS, JavaScript, and Flask for local preview.

## Run locally
```bash
pip install -r backend/requirements.txt
python backend/app.py
```
Open http://127.0.0.1:5000
